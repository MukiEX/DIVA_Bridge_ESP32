DIVA Bridge ESP32 Setup

Firmware in this page: —

Board & connection

    Not connected

    This browser has no Web Serial. Use Chrome or Edge on a computer.

    Install firmware

    Install also writes the settings from the Settings tab, so fill those in first (at least Wi-Fi).

    Settings

    Takes about a second; the board restarts with the new settings. Once it's on Wi-Fi you can also change these on its own page at http://diva-bridge.local/.

    Screen preview & background picture

    Any picture works: it's scaled to fill the screen and cropped to fit. Drag the preview to choose which part shows. The preview shows the screen with your rotation and backdrop settings, which are written with Write settings or Install. A picture is made for the rotation chosen when you write it; change the rotation later and the watch re-crops it to fit.

    No serial console on this board

    The watch's only USB-C port is the controller port, so it has no console. Its status, USB tree and live tester are on its own web page: http://diva-bridge.local/ (the IP is also shown on the watch screen).

    Status

    Connect to see the running firmware's status.
